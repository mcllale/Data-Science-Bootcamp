# Data-Science-Bootcamp
A compilation of projects completed with HyperionDev's Data Science Bootcamp.

## Projects
This repo contains of the following projects:
- Task Manager
- Data Analytics and Exploration
- Machine Learning (ML - Unsupervised)
- Machine Learning (ML - Supervised)
- Neural Networks
- Natural Language Processing (NLP) Applications

**Libraries:**
- spaCy (text preprocessing)
